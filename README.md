# myLLMwiki — Personal Intelligence System

개인 경험과 지식을 **관찰 → 구조화 → 예측 → 실행 → 오차 → 업데이트 → 전이 → 체화**하는 Obsidian 기반 학습 시스템.

## 핵심 목표
1. 많이 기록하는 것이 아니라 예측력을 높인다.
2. Case → Prediction → Result → Error → Model Update의 계보를 남긴다.
3. 공통 원리와 환경별 구현을 분리한다.
4. AI는 검색·반증·오차분석 Trainer로 사용한다.
5. 최종적으로 절차를 사고와 행동에 체화한다.

## 영역
- Electrical Engineering
- Education
- Strategy / 판짜기 (Kendo, Chess, Poker)
- NYTimes / World Model
- Meta / Self Model
