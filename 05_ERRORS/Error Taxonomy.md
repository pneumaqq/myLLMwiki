# Prediction Error Taxonomy

1. **information-gap** — 필요한 정보가 없었다.
2. **missing-variable** — 중요한 변수를 모델에 넣지 않았다.
3. **wrong-causality** — 관계의 방향/기제를 잘못 이해했다.
4. **opponent-model** — 행위자의 목표·정보·반응을 잘못 추정했다.
5. **base-rate-neglect** — 기준 빈도를 무시했다.
6. **overgeneralization** — 적은 사례를 넓게 일반화했다.
7. **environment-mismatch** — 다른 환경의 원리를 과도하게 전이했다.
8. **calibration** — 확신 수준이 실제 적중률과 맞지 않았다.
9. **execution** — 모델보다 실행 과정에서 실패했다.
10. **noise** — 현재 모델로 설명하기 어려운 우연/변동.

오류 분류 자체도 가설이다. 억지로 하나만 고르지 않는다.
