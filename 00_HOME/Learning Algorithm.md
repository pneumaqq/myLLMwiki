# Personal Predictive Learning Algorithm

1. **Observe** — 사실/관찰과 해석을 분리한다.
2. **Retrieve** — 구조가 유사한 과거 Case를 찾는다.
3. **Model** — 변수, 관계, 피드백, 행위자, 시간축을 그린다.
4. **Base Rate** — 유사 상황의 기준 빈도와 외부 근거를 확인한다.
5. **Competing Hypotheses** — 최소 2개의 대안 가설을 유지한다.
6. **Predict** — 결과·확률·시간범위·반증조건을 기록하고 Lock한다.
7. **Act** — 정보가치가 높고 손실이 제한된 행동을 우선한다.
8. **Compare** — 실제 결과와 예측을 비교한다.
9. **Error** — 오차 유형을 분류한다.
10. **Update** — 모델을 수정하되 과거 버전을 지우지 않는다.
11. **Transfer** — 다른 환경에서 재검증한다.
12. **Internalize** — 살아남은 원리를 직관으로 압축한다.

## 자동모드 해제 조건
큰 손실 가능성 / 처음 보는 환경 / 현실과 반복 불일치 / 강한 감정·피로 / 지나치게 높은 확신.
